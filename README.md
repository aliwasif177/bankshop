# BankShop

A simple banking backend written in Go. It models accounts, entries, and money
transfers between accounts, with database access generated by
[sqlc](https://sqlc.dev) on top of [pgx](https://github.com/jackc/pgx) and
schema versioning via [golang-migrate](https://github.com/golang-migrate/migrate).

## Features

- **Accounts** — create and query bank accounts with an owner, balance, and currency
- **Entries** — a ledger of balance changes (positive or negative) for an account
- **Transfers** — move money between two accounts, recording matching entries
  for both sides and updating balances atomically inside a DB transaction
- Fully generated, type-safe database queries via `sqlc`
- SQL schema migrations via `golang-migrate`

## Tech Stack

- Go
- PostgreSQL
- [sqlc](https://sqlc.dev) — generates Go code from SQL
- [pgx/v5](https://github.com/jackc/pgx) — PostgreSQL driver
- [golang-migrate](https://github.com/golang-migrate/migrate) — schema migrations
- [testify](https://github.com/stretchr/testify) — testing

## Project Structure

```
.
├── db
│   ├── migration   # SQL schema migrations (up/down)
│   ├── query       # Raw SQL queries used as sqlc input
│   └── sqlc        # Generated Go code (models, queries, store)
├── util            # Shared helpers (random test data generators)
├── Makefile        # Common dev commands (db, migrations, tests, sqlc)
├── sqlc.yaml       # sqlc configuration
└── go.mod
```

## Database Schema

Three tables: `accounts`, `entries`, and `transfers`.

- `accounts` — `id`, `owner`, `balance`, `currency`, `created_at`
- `entries` — `id`, `account_id`, `amount`, `created_at` (amount can be positive or negative)
- `transfers` — `id`, `from_account_id`, `to_account_id`, `amount`, `created_at` (amount is always positive)

## Getting Started

### Prerequisites

- Go 1.26+
- Docker (to run PostgreSQL)
- [golang-migrate CLI](https://github.com/golang-migrate/migrate#cli-usage)
- [sqlc CLI](https://docs.sqlc.dev/en/latest/overview/install.html)

### Setup

```bash
# start a PostgreSQL container
make postgres

# create the database
make createdb

# run schema migrations
make migrateup
```

### Run tests

```bash
make test
```

### Regenerate sqlc code

After changing anything under `db/query` or `db/migration`:

```bash
make sqlc
```

## Makefile Commands

| Command          | Description                                   |
|------------------|------------------------------------------------|
| `make postgres`  | Start a PostgreSQL container via Docker         |
| `make createdb`  | Create the `simple_bank` database               |
| `make dropdb`    | Drop the `simple_bank` database                 |
| `make migrateup` | Apply all schema migrations                     |
| `make migratedown` | Roll back all schema migrations              |
| `make sqlc`      | Regenerate Go code from SQL via sqlc            |
| `make test`      | Run the test suite with coverage                |
